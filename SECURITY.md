# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 2.x | yes |
| 1.x | no |

## Reporting a vulnerability

Report vulnerabilities privately through
[GitHub security advisories](https://github.com/arthurtumanyan/libriak-c/security/advisories/new)
or by e-mail to arthurtumanyan@gmail.com. Do not open a public issue.

Include the affected version, a description of the impact and, if possible,
a reproducer. Reports are acknowledged within 7 days; fixes are released as
a patch version with a CHANGELOG entry crediting the reporter unless asked
otherwise.
